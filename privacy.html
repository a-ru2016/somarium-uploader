日本語

  1. このツールについて: Somarium Uploader は、YouTube チャンネル「体内ミクロ紀行」「Somarium」の運営者が、自分のチャンネルに動画を上げるためだけに使う私用のツールです。一般の利用者には提供していません。
  2. YouTube API Services の利用: このツールは YouTube API Services を使います。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。
  3. 取得する情報: 運営者が Google の画面で許可したときに発行される OAuth のトークンと、運営者のチャンネルの情報（チャンネル名・ID など）、運営者の動画の情報と視聴データ（YouTube Analytics）です。運営者以外の人の個人情報は取得しません。
  4. 使い方: 取得した情報は、運営者のチャンネルへの動画のアップロード、その動画のタイトル・説明・タグ・サムネイル・字幕の設定、運営者自身による視聴データの振り返りにだけ使います。
  5. 保存と共有: トークンは運営者の PC にだけ保存します。取得した情報（アップロードの記録と、運営者の動画の視聴データの集計）は、運営者の PC と、運営者だけが使う非公開の GitHub リポジトリ（作業記録の保管のため）に保存します。第三者に販売・提供・共有しません。広告には使いません。
  6. 取り消し: このツールへのアクセスは、Google アカウントのサードパーティ アクセスの設定でいつでも取り消せます。取り消すと、保存されたトークンは使えなくなります。
  7. Cookie: このツールとこのウェブサイトは Cookie を使いません。
  8. 変更: このポリシーを変えるときは、このページを更新し、制定日を改めます。
  9. 連絡先: socialsurvivors2026@gmail.com

English

  1. About this tool: Somarium Uploader is a private tool used only by the operator of the YouTube channels "体内ミクロ紀行" and "Somarium" to upload videos to their own channels. It is not offered to the public.
  2. Use of YouTube API Services: This tool uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.
  3. Information collected: The OAuth tokens issued when the operator grants access on Google's consent screen, the operator's channel information (such as channel name and ID), and information and analytics (YouTube Analytics) of the operator's own videos. No personal information of anyone other than the operator is collected.
  4. How it is used: Only to upload videos to the operator's channels, to set the title, description, tags, thumbnail and captions of those videos, and for the operator's own review of their video analytics.
  5. Storage and sharing: Tokens are stored only on the operator's computer. Retrieved information (upload records and summaries of the analytics of the operator's own videos) is stored on the operator's computer and in a private GitHub repository used only by the operator (to keep work records). It is not sold, provided or shared with third parties, and are not used for advertising.
  6. Revoking access: Access can be revoked at any time from the third-party access settings of your Google Account. Once revoked, the stored tokens can no longer be used.
  7. Cookies: Neither this tool nor this website uses cookies.
  8. Changes: If this policy changes, this page will be updated with a new effective date.
  9. Contact: socialsurvivors2026@gmail.com
